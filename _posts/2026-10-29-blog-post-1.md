Today I've released version 0.1.0 of RFS, a C++ library for performing multi-object tracking using Random Finite Set (RFS)-based filters!

You can check it out on [Github](https://github.com/AidanBlair/RFS/).

During my PhD and since then, all of my multi-object tracking, multi-sensor control, and information fusion research has been done in MATLAB, building off a codebase initially developed by Ba-Tuong Vo. Although the code works well and there's a lot to love about MATLAB, as time passed and I worked on more projects with scripts that were thousands of lines long and took days to run, I always had the thought in the back of my mind of developing a library in a faster language such as C++, with implementations of different RFS filters, information fusion methods, multi-sensor control methods, etc., which can all plug-and-play with each other.

Well, today I've released the first version of that dream! It's pretty bare-bones at the moment, but there is a working implementation of an LMB filter, including models for target birth, motion, detection and measurement, and OSPA and OSPA(2) metrics. I've also included a simple example scenario and script that can be run and inspected to get an idea of how it works.

In the future, I aim to add a lot more features, including different types of RFS filters, centralized and distributed sensor network models, multiple information fusion and multi-sensor control implementations, visualizations and deeper statistical analysis, and synthetic scenario generation.

Feel free to try it out, and all feedback is welcome!

Aidan
